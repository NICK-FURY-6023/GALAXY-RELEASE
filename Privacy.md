1. Introduction

This Privacy Policy explains how this Discord music bot (“the Bot”) collects, uses, and protects information when used in Discord servers.
The Bot is designed to respect user privacy and strictly follows Discord’s Developer Terms of Service and API policies.

By inviting or using this Bot, you agree to the data handling practices described in this Privacy Policy.


---

2. Data the Bot Accesses

The Bot only accesses data that is necessary for its core functionality. This may include:

Discord user IDs and server IDs (used internally by Discord)

Message content only when a command is explicitly sent

Member and role information for DJ permission checks

Presence/activity status for optional Rich Presence (RPC) features

Music-related metadata such as track titles, artist names, and queue data


The Bot does not access private messages unless explicitly invited into a DM by a user.


---

3. Message Content Handling

The Bot reads message content only for the following purposes:

Processing prefix-based commands

Handling legacy commands where slash commands are not used

Responding to user-issued instructions


The Bot does not read, monitor, or analyze regular conversations.
Message content is not logged, stored, archived, or shared outside of Discord.


---

4. Slash Commands & Interactions

Slash commands are processed using Discord’s interaction system.
All interaction data is handled temporarily in memory and discarded immediately after the command execution.


---

5. DJ Roles & Permission System

The Bot accesses server member and role information to:

Verify DJ roles

Restrict sensitive music controls (skip, stop, volume, queue management)

Ensure fair and secure usage of music features


No role or member data is stored permanently.


---

6. Presence & Rich Presence (RPC)

If enabled, the Bot may access presence/activity information to:

Display music playback status via Rich Presence

Improve user experience during music sessions


Presence data is:

Optional

Temporary

Never stored or tracked


Users can opt out of presence-related features.


---

7. Last.fm Integration

If a user links a Last.fm account:

The Bot only uses the provided username to fetch publicly available scrobbling data

Authentication tokens are not shared or sold

The Bot does not access private Last.fm account details


Users can unlink their Last.fm account at any time.


---

8. Multi-Platform Music Sources

The Bot supports multiple public music platforms.
It does not download, redistribute, or permanently store copyrighted audio content.

Music playback is handled through streaming and third-party services in compliance with their terms.


---

9. Data Storage

The Bot does not store sensitive personal data off-platform.

Any temporary data (such as queue state or playback information) exists only in memory and is cleared automatically when no longer needed or when the bot restarts.


---

10. Data Sharing

The Bot:

❌ Does not sell data

❌ Does not share data with third parties

❌ Does not use data for advertising

❌ Does not use data for analytics or AI training


All data remains within Discord’s ecosystem.


---

11. User Control & Opt-Out

Users may:

Choose to use slash commands instead of prefix commands

Opt out of presence-related features

Remove the Bot from their server at any time


Removing the Bot immediately stops all data access.


---

12. Children’s Privacy

The Bot is not intended for users under the age required by Discord’s Terms of Service.
No effort is made to collect personal data from minors.


---

13. Security

Reasonable measures are taken to ensure secure operation of the Bot.
Bot tokens and credentials are kept private and are never exposed publicly.


---

14. Changes to This Policy

This Privacy Policy may be updated if required.
Continued use of the Bot after updates indicates acceptance of the revised policy.


---

15. Contact

If you have questions or concerns regarding this Privacy Policy, please contact the bot developer via the official support channel provided with the Bot.
